# Appsive website

Eerste lokale conceptversie van de bedrijfswebsite. De inhoud en diensten zijn een voorgestelde richting en moeten nog worden afgestemd op het bedrijf. Er zijn geen echte klantcases of bedrijfsresultaten toegevoegd.

## Bekijken

Open `dist/index.html` in je browser. Of start met Node.js een lokale preview:

```sh
node server.mjs
```

Open daarna http://localhost:4173. Stop de server met Ctrl+C.

Het contactformulier downloadt alleen een tekstbestand en verstuurt niets. De lettertypen komen van Google Fonts; zonder internet gebruikt de site een systeemlettertype.

## Werken aan de site

- GitHub is de echte opslag; de kopie op Google Drive is alleen een back-up en wordt alleen bij grote wijzigingen bijgewerkt.
- Werk in een eigen map buiten Google Drive (los van Taskly). Begin altijd met **Fetch origin / Pull** en eindig met commit en **Push origin**.
- Deze repository wordt openbaar voor GitHub Pages: zet hier nooit wachtwoorden, sleutels of privégegevens in.

## Nog afstemmen

- Definitieve bedrijfsnaam, logo, kleuren en diensten.
- Echte contactgegevens en eventuele bedrijfsgegevens.
- Echte projecten en beelden, als die beschikbaar zijn.
- Berichtverzending en privacytekst voordat de site publiek wordt gebruikt.
